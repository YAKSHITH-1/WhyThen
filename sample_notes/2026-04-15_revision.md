# Project Alpha Progress & Revision

Date: 2026-04-15

## Database Re-evaluation

Following memory benchmarks on our local desktop machine, we observed that ChromaDB's memory footprint increased with large corpora.
However, we decided to confirm ChromaDB for the MVP release because switching to LanceDB or Qdrant would delay the timeline by 3 weeks.
We will revisit LanceDB in Phase 2 if memory usage exceeds 1.5 GB.
